# 首发实战协同控制中心 (Launch Control Center Dashboard)

`Dashboard` 是专为 Apple 首发日实战设计的本地桌面监控协同中心，采用纯原生 Tkinter 构建，提供全中文、Apple 简约设计风格的实时全景看板。

---

## 1. 架构定位与安全隔离

控制中心严格遵循**只读观察者模式 (Read-only Observer)**：

- **完全线程隔离**：Dashboard 运行在独立线程，核心购买调度引擎运行在主业务线程中。
- **单向只读通信**：核心调度引擎通过 `DashboardAdapter` 异步推送只读状态快照，Dashboard 自身不向购买引擎下发任何执行指令。
- **崩溃容错保护**：即使用户误关闭控制中心窗口或 GUI 发生偶发渲染异常，底层的 Playwright 浏览器进程和主购买流程完全不受影响，仍会在 T0 触发加车并在到达接管点时置前浏览器。

---

## 2. 界面功能与模块布局

控制中心由以下核心看板组成：

### 2.1 全景实战状态徽章 (Hero Status Card)
- 顶部醒目状态胶囊，直观展示当前系统工作模式与最高优先级状态：
  - `【首发实战 · 生产状态】` (常驻绿色)：全链路就绪，正在低频监控官网；
  - `【首发实战 · 流程阻断】` (高亮红色)：命中会话失效等阻塞性异常，并提示终端恢复命令；
  - `【模拟演示 · 就绪】` (演示模式蓝色)：用于首发前离线演练。

### 2.2 预购开始倒计时 (Launch Countdown Widget)
- 针对 Apple 官方预购开售时刻（如 `2026-10-16 20:00:00 CST`）提供动态高精度倒计时。
- 格式化展示：`剩余 XX天 XX小时 XX分 XX秒`。

### 2.3 核心监控卡片矩阵 (Status Grid)
- **Apple Account 会话状态**：实时呈现登录态探针结果。若会话异常立即联动 Fail-Closed 阻断。
- **目标规格与 SKU 锁定**：展示目标机型（iPhone Duo）、颜色（星光白色）、容量（512GB）以及解析锁定的官方 SKU（`MK2P4CH/A`）。
- **线上渠道监控**：展示官网购买页当前状态（`即将发售` / `开放购买` / `不可购买`）与动态轮询间隔。
- **上海直营店自提监控**：并行展示上海 4 家官方直营店（香港广场、上海环贸 iapm、五角场、环球港）的店内自提现货状态。
- **通知系统与退避护盾**：展示飞书卡片推送状态与 RateGuard 频控/指数退避状态。

### 2.4 10 项首发实战就绪核验清单 (10-Item Checklist)
提供一目了然的绿/黄/红状态指示灯：
1. 配置文件完整性加载
2. 浏览器持久化 Profile 挂载
3. Apple ID 会话有效性探针
4. 官方动态 Catalog 解析锁定
5. 目标规格星光白色/512GB 预热
6. 线上通道随机抖动低频监控
7. 上海 4 家直营店映射与严格节流
8. RateGuard 边缘退避护盾常驻
9. 飞书移动端通知与本地警报
10. 人工安全接管与单飞锁机制

### 2.5 实时交互式日志终端 (Live Event Stream)
- 底部集成纯中文结构化日志流，按 INFO / WARNING / SUCCESS / CRITICAL 提供清晰高亮，方便首发实操时全景掌控内部运转。

## 3. 离线模拟演练模式 (Demo Mode)

在不访问任何 Apple 真实接口、不消耗任何真实网络的前提下，控制中心提供了内置的模拟演示驱动器，用于本地验证全套界面动画与状态跃迁：

```bash
python -m src.main --mode dashboard-demo
```

该模式将在本地内存中模拟以下完整业务生命周期：
1. 会话初始化与 Catalog 解析模拟；
2. 线上监控轮询与即将发售状态展示；
3. 直营店自提现货发现与声光报警；
4. T0 开售瞬时状态切换与人工接管移交。
