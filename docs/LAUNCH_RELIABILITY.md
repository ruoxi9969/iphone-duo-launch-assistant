# 首发运行准备与可靠性修复

目标为 iPhone Duo 星光白色 512GB，开售时间以 Apple 中国官网为准。示例配置使用北京时间 2026-10-16 20:00。

## 本次修复

- 线上监控只接受本次成功响应的目录；403、429、541 传递至退避器，不再退回旧页面或缓存冒充实时数据。请求有超时。
- `getReady` 表示配置准备，不触发购买。指定开售时间之前，即使目录的 `comingSoon=false` 也不会推进。
- 开售前预留最小请求间隔，并缩短跨越开售时间的等待，使下一次检查对齐开售时间。网络延迟和已有退避仍然生效。
- 自提请求有超时；开售前最后 15 秒让出共享页面锁，受到限流时立即结束该轮查询。
- 收到正式可购信号后重新加载购买页一次；规格核验读取当前页面目录，不再导航破坏已选配置。
- 正式流程成功或发生购买推进异常后，页面保留至用户关闭，供本人核对与付款。
- 正式启动持有进程锁，防止重复开启两个助手。
- 购买按钮未启用时继续低频等待。新版官网“继续”按钮可用时提示本人接管；不把它误认为旧版加车接口。真实加车仅点击一次，响应不确定时转交人工核对购物袋。
- 显式关闭飞书时允许使用本地声音；飞书启用时继续要求端到端验证。

## 本地运行

若使用本机已安装的 Google Chrome，可在私有 `config.yaml` 设置：

```yaml
browser:
  channel: chrome
  user_data_dir: ./browser_data
notifications:
  feishu:
    enabled: false
  sound:
    enabled: true
launch:
  launch_time: "2026-10-16T20:00:00+08:00"
```

先由本人在独立浏览器资料中登录，再运行 `python -m src.main --mode launch-dashboard`。
开售时请留在电脑旁。最终付款、验证码与身份验证由本人在 Apple 官方页面完成。

## 验证边界

新增离线回归包含真实无界面浏览器的本地拦截响应，用于验证 HTTP 拦截、最新响应与页面选项保留。离线测试不能证明真实开售时的服务容量或购买成功率。
`formal-runtime-verify` 仍在真实加车前阻断，不创建订单，计时不代表完整下单耗时。
登录资料、私有配置、缓存和浏览器工具快照均被 Git 忽略。
